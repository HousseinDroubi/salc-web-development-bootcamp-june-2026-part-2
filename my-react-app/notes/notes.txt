2- Folder Structure in React:
my-react-app/
├── node_modules/         # Auto-generated folder storing all installed third-party packages and dependencies
├── public/               # Static assets (favicons, logos) served directly at the root URL without bundling
├── src/                  # Core application source code
│   ├── App.tsx           # Root component, primarily used to define app-wide layout and client-side routing
│   └── main.tsx          # Entry point that grabs the root HTML element and mounts the React app into the DOM
└── vite.config.ts        # Configuration file for Vite (build settings, plugins, dev server options, path aliases)

3- JSX: 
JSX (JavaScript XML) is a syntax extension for JavaScript that allows you to write
HTML-like markup directly inside your JavaScript files.
Under the hood, build tools like Babel or Vite compile JSX into
standard React.createElement() JavaScript function calls that
produce Virtual DOM objects.

4- SPA:
SPA (Single-Page Application) is a web application architecture where
the browser loads only a single HTML file (index.html) once.
As the user navigates or interacts with the app, React dynamically
swaps out components and updates the content on the screen
via JavaScript without reloading the entire page from the server.

5- React is an open-source JavaScript library for building fast,
interactive user interfaces—primarily for web applications—using reusable,
self-contained UI pieces called components.

6- DOM vs VDOM (Find more in i_1.png):
    a) in Vanilla HTML, CSS and JS:
    When working with vanilla html, css and js, any change in the DOM (like
    appendChild, removeChild, updated innerHTML, update innerText) will have
    to re-render the whole tree, which very slow.

    b) In React:
        1) VDOM (Virtual DOM) is a lightweight, in-memory JavaScript copy of the Real DOM used by React.
        2) React has two version of VDOM:
            * Previous VDOM: The Previous VDOM: A snapshot of what the UI looked like right before the state or data changed.
            * The New VDOM: The updated Virtual DOM generated after the state or data changed.
        How does react update the DOM:
        When the When data changes, React updates the VDOM first, compares it with the previous version of VDOM to find the exact differences (diffing), and then surgically updates only those specific elements in the Real DOM (reconciliation), so it does not re-render the whole tree.

7- All components must be wrapped in a single container

8- Functional components are standard JavaScript or TypeScript functions
that accept data as an object argument (called props)
and return JSX describing what should appear on the screen.
They are the modern standard for writing components in React and
use Hooks (such as useState and useEffect) to manage internal state
and side effects.

9- Component life-cycle:
    The component lifecycle refers to the series of distinct phases a
    React component goes through from the moment it is created
    until it is removed from the screen:

    * Mounting: The component is created, rendered for the first time, and inserted into the Real DOM.
    * Updating: The component re-renders because its state or incoming props have changed.
    * Unmounting: The component is removed from the Real DOM and destroyed (e.g., when navigating away or conditionally hiding it), where any active timers or subscriptions are cleaned up.
