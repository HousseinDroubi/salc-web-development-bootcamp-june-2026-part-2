1- SQL stands for Structured Query Language, it's used to manage data inside databases like PostgreSQL, MySQL...
2- With SQL, we can do the CRUD operations (Create, Read, Update, and Delete) in PostgreSQL.
3- Data are stored inside PostgreSQL using tables inside databases. One database can hold multiple schemas and tables.
4- Schemas are like folders inside a database used to organize tables. The default schema created automatically in every new PostgreSQL database is named public, and it is the one accessible by default when you connect to a database without specifying a schema.
5- MySQL vs. PostgreSQL are two big open-source database rivals.

When to choose which?
    - Choose MySQL if:
        * You are building a standard web app, content management system (like WordPress), or e-commerce site.
        * You want something quick to set up, easy to find shared hosting for, and optimized for fast, straightforward CRUD operations.
    - Choose PostgreSQL if:
        * You are building an application with complex business logic, financial transactions, or heavy data integrity requirements.
        * You need advanced features like spatial/geographic data (PostGIS), custom array types, heavy JSON storage, or complex analytical queries.
