Let's say that we want to use nodemon executable file:
    1- Add a script called "dev" inside scripts: (example)
        ...
        "scripts": {
            "dev":"nodemon index.js"
        },
        ... 

    2- Using executable file inside node_modules/.bin:
        node_modules/.bin/nodemon index.js
    3- Install nodemon globally:
        npm i -g nodemon
    Then, use:
        nodemon index.js
    
    4- Using npx:
        npx nodemon index.js # npx will search for nodemon, either in local project, or in the global node packages or inside its temporarily folder 

1- Definition of npx:
This command allows you to run an arbitrary command from an npm package (either one installed locally, or fetched remotely), in a similar context as running it via npm run

Reference: https://docs.npmjs.com/cli/v9/commands/npx
