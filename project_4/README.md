## 🛠️ Built With

### Frontend

- **HTML5** — Structure and markup
- **CSS3** — Styling and layout
- **JavaScript (ES6+)** — Interactive functionality and logic

### Backend & Database

- **Express.js** — Fast, unopinionated web framework for Node.js
- **Prisma ORM** — Next-generation Node.js and TypeScript ORM for type-safe database queries and migrations
- **PostgreSQL** — Powerful, open-source relational database management system
- **MVC Architecture** — Backend structured around Models, Views/API responses, and Controllers for clean separation of concerns
- **Service Layer Pattern** — Encapsulates business logic, keeping controllers lean and maintainable
- **JWT (jsonwebtoken)** — Secure token-based user authentication
- **Bcrypt** — Secure password hashing and comparison
- **Zod** — TypeScript-first schema validation with static type inference
- **CORS** — Middleware for enabling Cross-Origin Resource Sharing
- **Cookie-Parser** — Parse `Cookie` header and populate `req.cookies`
- **Dotenv** — Zero-dependency module to load environment variables
