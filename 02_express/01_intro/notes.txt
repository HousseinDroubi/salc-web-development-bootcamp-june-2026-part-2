1- IP Address:
* A unique numerical label assigned to every device on a network (like a digital mailing address) so data packets can find their destination.
* Public vs. Local: A public IP identifies your device on the global internet, whereas a private IP identifies it only within your local network (e.g., home Wi-Fi).
* Localhost (127.0.0.1): localhost is the standard hostname referring back to the computer you are currently using. It resolves directly to the loopback IP address 127.0.0.1.
* How 127.0.0.1 Works?
    Network traffic sent to 127.0.0.1 bypasses the physical network card and loops straight back to your local operating system—making it perfect for building, testing, and debugging apps offline.

2- url: A URL (Uniform Resource Locator) is the web address used to locate and access a specific resource—such as a webpage, image, or file—on the internet

3- Server: A computer or program that listens for network requests and sends back responses.

4- Port: A virtual endpoint (like a door number) that directs incoming traffic to a specific app on a server.

5- API: A bridge that lets two applications talk to each other and share data.

6- ExpressJS: A lightweight Node.js framework for building web servers and routing API requests quickly.

7- Params in URL: Dynamic variables path-encoded directly in the URL route (main form: /users/:id, e.g., /users/42).

8- Query in URL: Key-value pairs attached to the end of a URL after a ? (main form: ?key=value&key2=value2, e.g., /search?q=cat&limit=10).

9- Status Code: 3-digit numbers indicating request outcomes:

    a) 1xx: Informational

    b) 2xx: Success (e.g., 200 OK)

    c) 3xx: Redirection

    d) 4xx: Client Error (e.g., 404 Not Found)

    e) 5xx: Server Error (e.g., 500 Internal Error)
For more info about status code, check out the following url:
https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status

10- Request (req): The incoming message from the client to the server containing headers, URL path, parameters, query string, and payload data.

11- Response (res): The outgoing message sent from the server back to the client carrying the status code, response headers, and requested data (such as JSON or HTML).
